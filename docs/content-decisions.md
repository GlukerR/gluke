## 9. Текущее состояние контента

- Коллекция `projects` — 4 опубликованных кейса: Getic (1), Кипарис (2), WiederKraft (3), HouseGuru (4).
- Коллекция `site` — singleton `content/site.yml` с глобальным контентом.
- Поле `status` отвечает только за редакционный статус (`draft` / `review` / `published`).
- Состояние сотрудничества хранится отдельно в `engagement` (`active` / `completed`).
- Поле `year` не заполняется у текущих кейсов, потому что их периоды охватывают несколько лет; вместо него используется `period`.
- Схема `testimonial` удалена полностью: самостоятельных отзывов на сайте не будет.
