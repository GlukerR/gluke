# Индексация сайта: чек-лист по поисковикам

Что нужно сделать, чтобы `gluke.ru` индексировался в Google, Bing и Яндексе.
Техническая часть (canonical, sitemap, robots, Schema.org) уже на месте — см. `docs/seo-deployment.md`.
Тут — практические кнопки в панелях веб-мастеров и текущий статус.

## Состояние сайта (технически)

| Проверка | Статус |
| --- | --- |
| `robots.txt` | индексация разрешена, запрещён только `/api/`, sitemap объявлен |
| `sitemap.xml` / `sitemap_index.xml` | есть, разбит по языкам `en-US` и `ru-RU`, у всех URL проставлен `lastmod` (из поля `updated`, см. `pnpm lastmod`) |
| canonical / hreflang / x-default | корректные, абсолютные |
| Schema.org / Open Graph / Twitter | есть на всех страницах |
| Мета-тег `yandex-verification` | `820eb76ffe56a5df`, в `<head>` на всех страницах |
| Индексация | разрешена только для production (не для preview/dev) |
| `llms.txt` | есть — для AI-краулеров (ChatGPT/Perplexity/Claude) |
| IndexNow | авто-пинг всех URL сайта на каждый push в master (см. `scripts/postdeploy.mjs`). Шаг ждёт успешного деплоя коммита через GitHub Deployments API — токен Vercel не нужен |

## Актуальный статус (на дату последнего обновления)

| Поисковик | Статус | Примечание |
| --- | --- | --- |
| **Google** | ✅ главная в индексе | `site:gluke.ru` отдаёт главную |
| **Bing** | ✅ успешно проиндексировано | последний обход — вчера, всё разрешено, SEO-проблем нет |
| **Яндекс** | ⏳ принято в обработку | sitemap в очереди, обход до 1–2 недель |

## Google (Search Console)

1. [search.google.com/search-console](https://search.google.com/search-console) → Google-аккаунт.
2. «Добавить ресурс» → **URL-префикс** → `https://gluke.ru/`.
3. Подтвердить. Использованный способ — **TXT-запись DNS на reg.ru**:
   - тип `TXT`, имя `@`, значение `google-site-verification=Inx0oEnWiuVk6cFo5p5Tf8AkxBw7HCXvW3n7QRqxnaE`.
   - Если после подтверждения Google пишет «токен не найден» — запись может быть видна,
     проверь через `https://dns.google` / `https://1.1.1.1/dns-query`, потом повтори «Подтвердить».
     Ошибка на первом клике из-за распространения DNS — обычное дело.
4. Слева **Sitemap** → добавить `https://gluke.ru/sitemap.xml` → «Отправить».

---

## Bing (Webmaster Tools)

1. [bing.com/webmasters](https://www.bing.com/webmasters) → вход через Microsoft-аккаунт.
2. Добавить сайт или **«Import from Google Search Console»** (быстро, подтянет и sitemap).
3. **URL Inspection** → `https://gluke.ru/` → кнопка **«Request Indexing»** — ставит главную на переобход.
   - Старый статус «заблокировано robots.txt» — это кэш прежнего хостинга; после перезапроса
     на живом сайте всё разрешено, страница отдаёт 200.
4. **Sitemaps** → `https://gluke.ru/sitemap.xml` → «Submit».

Хороший признак успеха в Bing — «Успешно проиндексировано», «Обход контента разрешён: Да»,
«Получение страницы: Успешно», «Проблем с SEO не обнаружено».

---

## Яндекс (Вебмастер)

1. [webmaster.yandex.ru](https://webmaster.yandex.ru) → вход в Yandex ID.
2. «Добавить сайт» → `gluke.ru`. Подтверждение — **метатегом**
   (он уже стоит в `<head>`) → «Проверить».
3. **Индексирование → Sitemap-файлы** → добавить `https://gluke.ru/sitemap.xml`.
   - После отправки будет «в очереди на обработку», обработка занимает **до 1–2 недель**.
   - Предупреждение в «Диагностике» про «отсутствуют обработанные файлы» исчезнет само после обработки.
   - Прогресс смотреть в **Индексирование → Страницы в поиске**.
4. (Опционально) **Индексирование → Переобход страниц** → URL.
   - ВАЖНО про протокол: сайт добавлен как **`http://gluke.ru`**, поэтому в поле вводить
     строго `http://gluke.ru/` (или относительный `/`). Ввод `https://…` даст
     «Некорректный URL: адреса должны быть относительными или принадлежать текущему сайту».

### Про протокол http/https у Яндекса
Яндекс помнит домен с протоколом. Сайт добавлен как `http://gluke.ru`, но живой сайт
работает только на https (http редиректит на https). Яндекс сам следует за редиректом,
поэтому это не мешает индексации — но все ручные вводы в полях делай в `http://` виде
или относительным адресом. При желании можно добавить отдельным сайтом `https://gluke.ru`.

## Быстрые проверки статуса

- **Google:** `site:gluke.ru` в поиске Google.
- **Bing:** `site:gluke.ru` в Bing; или URL Inspection в панели.
- **Яндекс:** Индексирование → Страницы в поиске (обновляется порциями, не мгновенно).

## Правило после правок сайта

Вручную ничего отправлять не нужно: `git push` → CI собирает, Vercel деплоит и сам
назначает production-алиас на `gluke.ru` → джоб «Notify search engines» дожидается
успешного деплоя и пингует IndexNow (Bing узнаёт об обновлении сам). Google и Яндекс
подхватывают изменения при очередном обходе по sitemap, ориентируясь на `lastmod`.

Пинг можно отправить и руками, без CI и без каких-либо токенов — нужен только
ключевой файл из `public/`:

```bash
pnpm indexnow
```
