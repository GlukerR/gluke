## Задачи

### 1. Сгладить разницу в вёрстке между русской и английской версиями

**Статус:** ждёт решения (записано 10.08.2026).

**Суть проблемы.** Русская и английская версии сайта выглядят чуть по-разному: русские блоки выше, страница длиннее. Сетка, отступы и CSS у версий одинаковые — разницу создаёт только длина текста (русские фразы длиннее, кириллица в Manrope шире), из-за чего текст чаще переносится и блоки растягиваются.

**Замеры** (ширина окна 404px, главная страница):

| Элемент | Русский | Английский |
| --- | --- | --- |
| Заголовок hero | 122px | 122px |
| Описание под заголовком | 107px (4 строки) | 80px (3 строки) |
| Блок «Опыт в цифрах» | 267px | 245px |
| Вся страница | 8471px | 8300px |

**Предложенные варианты:**

1. Укоротить русские тексты в `content/site/ru.yml` — самый простой и безопасный способ (переводы уже есть в `en.yml`).
2. Зафиксировать высоты/минимальные высоты блоков — рискованно: длинный текст может обрезаться.

Идеального совпадения версий добиться нельзя (это нормально для многоязычных сайтов), но разницу можно сгладить вариантом 1.

**Что не менять:** логику сайта, вёрстку и CSS под эту задачу не трогаем.

2. `i18n/locales/ru.ts` + `en.ts` — заголовок/описание категории;

**Новый шаблон НЕ нужен (выяснено 31.08.2026 при разборе кода).** «Ролики по порядку
+ краткое описание» уже поддерживается текущей моделью кейса без каких-либо правок:
- у каждого медиа-элемента есть поле `caption` — подпись под видео/картинкой

Итог: «кейс-подборка» = обычный кейс с галереей роликов и подписями. Отдельный
